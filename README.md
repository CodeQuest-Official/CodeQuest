# CodeQuest

CodeQuest is an offline Android app for learning Python and JavaScript step by step. It is designed for beginners and uses short lessons, clear examples, and hands-on practice.

## What you can learn

- **Python:** 41 lessons covering fundamentals, variables and data types, conditions, loops, lists and data, functions, and beginner projects.
- **JavaScript:** 41 lessons covering fundamentals, variables, conditions, loops, arrays and objects, functions, and more advanced basics.
- **Learning paths:** Follow each course in order and see which lessons are complete or still locked.
- **Practice:** Write code in the in-app editor, arrange code lines, find mistakes, fill in blanks, predict output, and answer quizzes.
- **Assessments:** Take chapter tests with 10 questions and a final exam with 20 questions. Results and learning progress are stored locally.
- **Progress:** Earn XP for completed lessons and passed tests.
- **PHP:** Planned for a future update and not currently selectable.

## Code checking

CodeQuest does **not** compile or execute Python or JavaScript. Exercise answers are checked on the device using local text and structure rules. This is a learning aid, not a real programming environment.

## Privacy and offline use

- No account, backend, database, analytics, or ads.
- The app does not request internet access.
- Your name, selected course, progress, and XP are saved in private app storage on your device.
- Code answers are checked locally and are not uploaded.
